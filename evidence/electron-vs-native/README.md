# Electron vs native: evidence tables

Images and sources for the pingdotgg/t3code discussion about moving the desktop client off Electron.

- `*.png`: rendered tables (2x)
- `*.html`: the table sources, standalone
- `build.mjs`: renders the HTML to PNG with playwright-core (expects simple-icons SVGs in `../icons`)

All figures come from the sources cited in each table's footer and in the discussion.
